# Smart Schedule — Metryki sukcesu (revenue)

| Metryka | Jak mierzymy | Cel |
|---|---|---|
| Rentowność portfela | marża / % projektów dowiezionych z zyskiem | rosnąca |
| ROI inwestycji w zasoby | zwrot z zakupu/szkolenia (koparka, kompetencja) — prognoza vs wynik | dodatni ROI |
| Uniknięte straty na nierokujących projektach | wartość uratowana przez ubicie przed startem (PLN) | rosnąca |
| Kary umowne | wartość kar uniknionych / zredukowanych (PLN) | malejące kary |
